Запуск программы:

    1. Если папки node_modules нет или есть проблемы: npm install express sqlite3
    1. Перейдите в папку с проектом (cd ~/3_дз)
    2. Запустите файл для создания бд с таблицами (node create_tables.js)
    3. Запустите сервер командой (node server.js)
    
Если же вы решите удалить не только файл бд, но и папку с ним и не захотите создавать папку заново вручную,а также 
если не хотите вводить вручную команду для запуска создания таблиц, то вот решение: 

node setup.js - данный скрипт сделает всё за вас. Создаст и папку для хранения бд, и саму бд

Новые методы и команды помечены слева сбоку -> --- НОВИНКА!!!

И всё готово! 

Пример создания сообщения: ("text":"Укажите здесь любой текст","authorId":Укажите_здесь_айди_автора*)
*напоминание команды для получения списка всех пользователей: /api/users

И разумеется не забудьте про \" для каждой кавычки в сообщении, иначе будет ошибка!

1 вариант: curl -X POST http://localhost:3000/api/messages -H "Content-Type: application/json" -d "{\"text\":\"Ну это понятно\",\"authorId\":2,\"roomId\":2}"

2 вариант: curl -X POST http://localhost:3000/api/messages -H "Content-Type: application/json" -d "{\"text\":\"Привет всем из Стерлитамака\",\"authorId\":1,\"roomId\":1}"


--- НОВИНКА!!! Пример обновления сообщения:

curl -X PATCH http://localhost:3000/api/messages/1 -H "Content-Type: application/json" -d "{\"text\":\"Поздравляю всех с Новым Годом!\"}"

--- НОВИНКА!!! Пример удаления сообщения:

curl -X DELETE http://localhost:3000/api/messages/1

--- НОВИНКА!!! Пример обновления пользователя:

curl -X PATCH http://localhost:3000/api/users/1 -H "Content-Type: application/json" -d "{\"username\":\"Аркадий\",\"avatarColor\":\"#ff0000\"}"

--- НОВИНКА!!! Пример удаления пользователя:

curl -X DELETE http://localhost:3000/api/users/1

--- НОВИНКА!!! Пример обновления комнаты:

curl -X PATCH http://localhost:3000/api/rooms/1 -H "Content-Type: application/json" -d "{\"name\":\"Новогодний корпоратив\",\"description\":\"Новый Год на носу!\"}"

--- НОВИНКА!!! Пример удаления комнаты:
